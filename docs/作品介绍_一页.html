自助打印真正难的不是“把文件发到打印机”，而是打错、拿错、留下这三件事。 思印客把「上传 → 体检 → 计价 → 支付 → 打印 → 取件 → 删除」做成一条 可审计的交付链路：打印前先告警风险，打印中看得见真实设备，打印后用取件码与现场照片留证。

01

为什么现有方案不够

打错才被发现彩页按黑白付、奇数页双面、混排尺寸、空白页，都在出纸后才暴露，纸张和钱已经花掉。
拿错没人能证明纸堆放在托盘上，谁取的、什么时候取的、有没有拿错，全靠人工回忆。
文件留在机器里源文件长期滞留在服务器与打印终端，删除动作没有记录，隐私无从追溯。

03

三个阶段做了什么

BEFORE打印前 · 先检查再收钱

  • 空白页、彩色页、低分辨率图、混排尺寸、双面奇数页风险提示
  • 论文 / 作业 / 实验报告 / 公文等 7 套格式模板打分与一键修复
  • A3 自动拆 A4、扫描件 OCR、多页合一排版
  • 本地识别身份证 / 手机号 / 银行卡并一键打码
  • 空白页不计费，前端预估与后端结算同一套逻辑

DURING打印中 · 真实设备可查

  • Windows（SumatraPDF）与 Linux（CUPS）双客户端，旧打印机零配置接入
  • 队列锁 + 条件更新，双客户端并发不重复抢单
  • 心跳、纸量、四档状态、R1–R6 告警集中管理
  • 智能选机：按队列、等待、距离、纸量与能力给出推荐理由
  • 错峰预约出纸、班级批量姓名封皮、多人拼单

AFTER打印后 · 交付可证明

  • 手机端取件码，T5 屏在取件态显示大号码并可点击确认
  • 取件幂等记录时间、序号与乱序，乱序触发告警
  • X5 摄像头以空托盘为基准，抓拍出纸现场图并绑定订单
  • 预估价与结算价同一套规则，前端不另算一份
  • 过期、完成、主动删除三类动作写入删除记录可审计
04

四个可演示的差异点

旧打印机零配置接入图形向导只填服务器地址，自动发现本机队列并生成 4 位接入码，管理端批准即下发专属令牌，设备 8 秒上线。
T5 实时取件终端串口接收真实状态、纸量、价格与取件码；三档链路状态区分连接中 / 在线 / 离线，未知数据一律显示 --。
X5 出纸视觉证据出纸事件带唯一标识与现场照片，只在活动订单窗口上报，把“已出纸”从口头承诺变成可回看的证据。
体检与交付承诺打印前提示三类风险；下单给出 ETA，超时免单与格式不符重印走独立状态机，不把提交打印命令等同于已出纸。
