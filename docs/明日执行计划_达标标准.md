**串口协议（定死）**

```
每行一帧，以 \n 结尾，单行 < 512 字节
```

## 四、T5-E1 + 3.5" 屏：核心加分项，按四档推进

> 这块板是我们的**唯一自研硬件**，24 分里最值钱的不是「显示文字」，而是**它是一个独立嵌入式终端**：有自己的屏、自己的触摸、自己的喇叭、自己的网络。下面的四档设计，就是把这四样东西全部用上。

### 4.1 能力清单（用满，不要浪费）

| 硬件能力 | 现在容易被浪费 | 明天怎么用 |
|---|---|---|
| 480×320 TFT + ILI9488 | 只显示一行字 | 分区布局：品牌栏 / 主信息区 / 底部纸量与在线状态 |
| **GT1151QM 触摸** | 完全没用 | 取件确认按钮、静音按钮、左右翻页（第 2、3 名排队订单） |
| 音频输出 | 完全没用 | 取件播报「尾号 5218 请取件」，预置 wav，不做实时合成 |
| WiFi（板载） | 只当串口用 | **主通道 HTTP 轮询（3 秒）**；串口只作兜底，断网自动切 |
| 8MB Flash + 16MB PSRAM | 没用 | 缓存最后 20 帧状态 + 2 张提示图，断电重启立刻有画面 |

> 关键认知：**主通道走 WiFi、串口只做兜底**，才叫「充分利用」。只走串口，评委看到的是一个"显示器"；WiFi + 本地缓存 + 触摸 + 语音，才是一个"终端"。

### 4.2 四个画面（评委 10 秒能看懂）

| 画面 | 内容 | 设计要点 |
|---|---|---|
| **空闲** | 「可打印」+ 单价 0.20 元/张 + 纸量条（绿/黄/红） | 字大到 3 米外能读；纸量条让评委知道我们读了打印机状态 |
| **忙** | 当前订单标题（截断）+ 进度「第 2/5 页」+「前面还有 2 人」 | 不要放进度条动画，放文字，稳 |
| **可取件（核心画面）** | **取件码 5 位，字号 160–200px，占屏 60%** + 黄黑闪烁底色 + 底部「轻触屏幕确认取件」 | 这是全场最值钱的一屏，评委拍照就拍它 |
| **异常覆盖层** | 缺纸 / 卡纸 / 离线，半透明红条压在当前画面顶部 | 不抢主信息，但一眼可见 |

补充一条**演示态角标**：右下角常驻小字 `T5AI · LVGL · WiFi`。这不是装饰，是让评委 1 秒知道「这是自研嵌入式终端，不是平板套壳」。

### 4.3 数据通道与降级（写死，不现场讨论）

```
主通道：板子 --HTTP GET--> /api/display/{device_id}/state   每 3 秒
        失败 3 次（约 9 秒）→ 切串口
串口：  工控机 -> /dev/ttyACM0  每 2 秒一行 JSON  {"s":"idle","q":2,"p":180,"c":"","t":...}
        6 秒无帧 → 画面置灰，保留最后一帧（不清屏）
恢复：  串口有帧且 HTTP 恢复 → 5 秒内切回 WiFi，画面右上角 WiFi 图标恢复
```

### 4.4 四档验收（按顺序打勾，做不到就停在上一档）

| 档位 | 内容 | 达标标准 | 值多少 |
|---|---|---|---|
| **铜** | 固定文字上屏 | 上电 3 秒内出现「思印客 · 可打印」，不花屏、不死机 | 保底，不算分 |
| **银** | 串口真数据三态 | 后端改队列 → 屏 5 秒内变态；拔网线 6 秒置灰但保留最后一帧；连跑 10 分钟不崩 | 提交 3 的 8 分 |
| **金** | 触摸确认取件 + 语音叫号 | 点屏幕「确认取件」→ 后端订单变 `picked` 且写 `pickup_seq`；进入可取件态 1 秒内播报「尾号 5218 请取件」，点静音停止；重复点幂等 | 提交 4 的 4 分 + 演示加成 |
| **钻** | WiFi 主通道 + 串口兜底自动切换 | 拔网线：9 秒内自动切串口仍正常显示；插回：5 秒内切回 WiFi，右上角图标恢复；全程不清屏、不重启 | 现场独有加分点，答辩主推 |

### 4.5 技术路径（不重新造轮子）

| 层 | 用什么 | 说明 |
|---|---|---|
| 工程基座 | `apps/games/lvgl_games` + `TUYA_T5AI_BOARD_LCD_3.5.config` | 板级配置与 ili9488 驱动已在 SDK 里验证过，直接改 UI，不动驱动 |
| UI | LVGL 4 个 screen + `lv_timer` 3 秒轮询 | 不写自绘，全部用 LVGL 控件，改样式最快 |
| HTTP | 板载 WiFi + SDK 的 HTTP 客户端 | 与 `client/main.py` 用同一个 token |
| 串口 | UART 读行 + `cJSON` | SDK 已带 cJSON，直接解析 |
| 语音 | 预置 3 段 wav（取件/请稍候/静音确认） | **不做 TTS 实时合成**，现场不可控 |
| 缓存 | littlefs 存最后一帧 JSON | 断电重启先渲染缓存，避免白屏 |

### 4.6 明确不做（防止时间被吃掉）

不做：页面切换动画、多语言、设置页、OTA 升级、自定义字体渲染中文以外的字符、摄像头预览。
中文用 LVGL 内置思源字体子集，**只保留业务用到的字**（约 200 字），否则字库会把 Flash 撑爆。
