# 思印客 Silnk 租户开通操作手册

适用对象：平台运营人员（开通、续期、停用、结算）与租户管理员（日常查看与定价）。
本手册对应系统版本：含订阅生效、设备配额、用户点位入口、营收与结算。

---

## 一、先弄清三个入口

| 入口 | 地址 | 谁使用 | 用什么登录 |
| --- | --- | --- | --- |
| 平台管理端 | `https://silnk.cn/admin/tenants.html` | 平台运营 | 平台 `SECRET_KEY` |
| 租户控制台 | `https://silnk.cn/tenant/` | 租户管理员 | 开通时生成的租户密钥 `sk_...` |
| 用户下单入口 | `https://silnk.cn/?t=<租户ID>` | 来打印的用户 | 免登录即可选机、上传 |

三个链接不要混用：
- 租户密钥只能进租户控制台，访问平台接口会被拒绝（401）。
- 平台密钥可以管理所有租户，不要交给客户。
- 用户入口带 `?t=` 参数，只显示该租户的设备；不带参数时进入平台默认租户。

---

## 二、开通前准备

先和客户确认 6 件事，再动手开通：

1. 租户 ID：建议用小写英文/数字，例如 `deke`、`campus-east`，开通后不改。
2. 租户名称：展示在用户端选机区和控制台，例如「德科文印室」。
3. 套餐名：内部标识即可，例如 `starter`、`pro`。
4. 打印机上限：填实际允许接入的台数；填 `0` 表示不限量。
5. 订阅到期日：可留空表示不限期；到期后该点位会自动停止接单。
6. 平台抽成：默认 10%，按合同填；填 0 表示不抽成。默认自营租户固定为 0。

同时确认收款方式。当前系统是「平台统一收款 + 线下结算」，没有开通自动分账，见第八节。

---

## 三、平台端开通租户

1. 打开 `https://silnk.cn/admin/tenants.html`。
2. 点右上角「密钥」，输入平台 `SECRET_KEY`，保存。密钥只存本机浏览器。
3. 在「开通租户」卡片填写：
   - 租户 ID（必填）
   - 名称、联系方式
   - 套餐名
   - 打印机上限（0=不限）
   - 平台抽成 %
   - 订阅到期日（可空）
4. 点「开通租户」。
5. 成功后页面显示两块内容，务必当场交付客户：
   - 租户密钥（只显示这一次，关闭后列表只显示脱敏值）
   - 用户入口链接 `https://silnk.cn/?t=<租户ID>`

如果提示「租户已存在」，换一个租户 ID，不要重复开通。

---

## 四、交付给客户的内容

给客户三样东西，缺一不可：

1. 租户控制台地址：`https://silnk.cn/tenant/`
2. 租户密钥：`sk_...`（一次性明文，建议让客户登录后自行保管）
3. 用户下单入口：`https://silnk.cn/?t=<租户ID>`，用于贴二维码或放到桌面快捷方式

提醒客户：
- 密钥不要发到公开群，不要截图外传。
- 用户入口必须带 `?t=`，否则用户会进入平台默认租户，看不到自己的机器。

---

## 五、打印机接入

打印机客户端使用平台密钥接入，`TENANT_ID` 决定设备归属。

每台机器需要设置 4 个环境变量：

```
SERVER_HOST=https://silnk.cn
SECRET_KEY=<平台 SECRET_KEY，不是租户密钥>
PRINTER_DEVICE_ID=<该机器唯一 ID，例如 deke-01>
TENANT_ID=<租户 ID，例如 deke>
```

注意：
- 同一个租户下多台机器，`PRINTER_DEVICE_ID` 必须不同，否则心跳会互相覆盖。
- `TENANT_ID` 写错会归到别的租户或默认租户，用户端就看不到这台机器。
- 新设备接入会校验打印机上限；超限时客户端注册失败，需要平台端先调高上限。
- 已接入的旧设备重启重连不受上限影响。

接入后自检：
1. 平台端「设备」页能看到该设备，状态在线。
2. 租户控制台「本租户设备」能看到它，纸张与心跳正常。
3. 用用户入口打开下单页，选机区只出现本租户设备。

## 六、订阅维护（平台端）

在租户卡片的编辑行修改，改完点「保存订阅」：

- 套餐：仅作标识，不影响计费逻辑。
- 上限：改大后才能接入更多新设备；改小不会踢掉已有设备，但新增会被拒。
- 到期：到期后该租户用户端不再展示设备、下单被拒，租户也不能改价。
- 抽成：只影响之后的结算，不追溯已结算批次。

停用 / 启用：
- 点「停用租户」后，租户控制台立即无法登录（密钥 401），用户端不再展示该点位设备，下单被拒。
- 设备心跳仍会被记录，便于平台排查；但不会产生新订单。
- 重新点「启用租户」即可恢复。

密钥遗失：
- 页面目前没有自助重置密钥的入口（待做）。
- 需要平台运维在数据库 `tenants.secret_key` 中重置后，把新密钥线下交付客户。

---

## 七、租户控制台能做什么

客户登录 `https://silnk.cn/tenant/` 后：

- 订阅与点位：查看租户 ID、套餐、打印机上限、到期时间、当前服务状态。
- 本租户定价：设置本租户默认单价；订阅不可用时禁止修改。
- 设备 / 订单 / 告警：只看本租户数据，看不到其他租户。
- 营收与结算：今日、本月、累计、未结算应结，平台抽成与历史结算批次。
- 用户入口：卡片里可直接复制 `https://silnk.cn/?t=<租户ID>`。

计价优先级（前端预估与后端结算一致）：
设备独立价 > 本租户默认价 > 平台全局价。

## 八、营收与结算

### 统计口径

- 只统计已付款订单（系统写入支付单号）。
- 未付款订单不计；超时免单（`waived`）不计。
- 下载、预览、未付款入队都不算营收。

### 结算操作

1. 平台端租户卡片查看「待结」金额与单数。
2. 点「结算待结」，确认后系统生成一条结算批次：
   - 流水 = 该租户全部已付款未结算订单金额
   - 抽成 = 流水 × 当前抽成比例
   - 应结 = 流水 − 抽成
3. 同一批订单会被打上已结算标记，重复点不会重复结算。
4. 系统只记账，不自动打款；按合同线下转账给租户，转账记录由平台自行留档。

### 边界说明

- 支付宝自动分账、自动续费尚未接入，页面已标注为待做。
- 当前收款为平台统一收款，租户不单独持有收款通道。
- 资料库是平台级公共库，暂未按租户隔离。

## 九、常见问题排查

### 用户打开链接看不到打印机

按顺序检查：
1. 链接是否带 `?t=<租户ID>`，拼写是否与平台端一致。
2. 租户是否被停用或订阅已到期（平台端卡片状态）。
3. 设备是否在线（平台端「设备」页，超过 60 秒无心跳即离线）。
4. 设备 `TENANT_ID` 是否填错，导致归到了别的租户。

### 客户端注册失败

- 提示 403 且原因是「已达打印机上限」：调高上限，或停用不用的旧设备后再接入。
- 提示订阅不可用：平台端续期或启用该租户。
- 提示密钥无效：检查 `SECRET_KEY` 是否为平台密钥，是否与后端环境变量一致。

### 租户控制台登录 401

- 租户被停用，或密钥输错。
- 租户到期不会导致 401，但页面会显示服务暂停，且不能改价。

### 有订单但营收为 0

- 订单未真正付款（没有支付单号）。
- 订单被超时免单。
- 订单属于其他租户，检查设备归属与 `TENANT_ID`。

### 结算按钮点了没有金额

- 该租户没有「已付款且未结算」的订单。
- 可能已经结算过，去租户控制台或平台接口查看结算批次。

## 十、开通检查清单

- [ ] 租户 ID 已确认，未与现有租户重复
- [ ] 上限、到期日、抽成比例已按合同填写
- [ ] 平台端已成功开通，密钥已一次性交付
- [ ] 用户入口 `?t=` 链接已生成并测试
- [ ] 打印机已设置 `TENANT_ID` 与唯一 `PRINTER_DEVICE_ID`
- [ ] 平台端与租户控制台都能看到该设备在线
- [ ] 用用户入口下一单测试单，确认金额与设备正确
- [ ] 已向客户说明：密钥保管、订阅到期影响、结算为线下打款
